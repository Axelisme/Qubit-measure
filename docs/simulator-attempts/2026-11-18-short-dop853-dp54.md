# 短 dop853 row 改用 DP5(4)

**讀者：** framework-dev、agent。查 短 dop853 row 改用 DP5(4) 的做法與證據。

## 核心思路

保留 family 契約，合格的短 row 在 CPU 和 OpenCL 走 DP5(4)。

## 實測

CPU wall 中位加速 1.4986 倍（`d45e87637` → `62844ad96`，d=24 的 `simultaneous_drive` 24 點、7 workers、三組排他 ABBA）。 見[原討論](../discussions/2026-11-18-short-dop853-dp54.md#考慮過的選項與比較)。

## 為何採用或否決

使用者接受 CPU 略低於名目門檻的結果。Intel Arc 的同裝置 tableau 配對也支持這條短段路徑。
