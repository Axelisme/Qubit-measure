# 讀出鏈的資訊上限：λ 指標、記錄層與分析層的損失、自校準

## 結論

1. **顯示只畫 λ。** 每點只畫 λ(x) = λ_讀出·λ_A(x)，不加區間。平均值、r₁ 和其他曲線都不顯示。區間只在分析時使用。
2. **讀出鏈裡的平均值和 r₁ 不和訊號成正比。** 讀出鏈沒有 relax，每次 A 的輸入是上一次的輸出。所以平均值反映的是穩態布居 q(x)，r₁ = κ·q(1−q)·λ。兩者都會隨 q 變形。只有 λ 和 A 的轉移呈線性：
   - T1 掃描：λ = −c·e^(−t/T1)
   - Rabi：λ ≈ c·cos θ
3. **基本假設下的逐點 λ。** 基本假設是：讀出雜訊在讀出之間獨立、鏈在穩態、同一點的讀出連續、每點只有兩個態在作用。在這組假設下：
   - 每點用白化後完整的 2×2 lag 矩陣，以非迭代的方式估 λ。這個估計在任何 SNR、任何拖尾下都沒有偏差。
   - 和只用 trace 相比，理論上 λ 的 sd 縮小 √2 倍。實際模擬中，參數 sd 縮小 1.0–1.7 倍。
   - 分析參數時，直接擬合存下的 lag 統計量，不擬合 λ̂ 點。
4. **第一性原理上限。** 假設讀出完全已知、每次讀出的 IQ 都記錄下來，在相同總時間下，讀出鏈在所有模擬條件下都勝過一般 relax 實驗：
   - amp Rabi：sd 小 2.2–240 倍
   - T1：sd 小 1.5–53 倍
5. **記錄層幾乎不損失資訊。** 讀出已知時，只存平均加 lag 0…4，參數 sd 最多是完整記錄的 1.18 倍。一般實驗只存平均，最多是完整記錄的 1.14 倍。
6. **損失幾乎都在分析層，主要有兩項：**
   - 讀出參數要從資料自己估。二階統計量對 g/e 中心和雜訊的約束很弱。另外，「讀出期間的 e→g 衰減 d」和「A 的 b′」之間有精確退化：λ 可以辨識，a′、b′ 個別不能。
   - 只用 λ，丟掉了平均值（q 通道）。
   以 T1（p_th 0.3、讀出衰減 20%、SNR 0.3）為例，一路往下的上限如下：

   | 情況 | T1 的 sd |
   |---|---|
   | oracle | 0.30% |
   | 讀出未知，用兩個通道 | 1.5% |
   | 讀出未知，只用 λ | 7.8% |
   | 逐點基本假設 | 25% |

7. **方向：採用自校準策略，不另做讀出校準。** 在「整段掃描是同一組兩態」的加強假設下，自校準的讀出鏈（全域兩態模型、兩個通道）和自校準的一般實驗（教科書模型，振幅和偏移當成待估參數）相比：
   - qubit 熱、或 SNR ≥ 0.3 時，讀出鏈大多勝出。
   - SNR 1 時全部勝出。
   - 只有 SNR 0.1 下的冷和中 qubit 會輸，sd 是一般實驗的 1.3–3 倍。

## 問題

這篇延續 [trace 不變量討論](2026-11-03-readout-chain-trace-invariant.md)。那篇的結論是輸出 Â 和 λ̂；之後的模擬和使用者裁決改變了指標的形式，也把問題擴大到兩件事：理論上限在哪裡，以及資訊在哪一層流失。

使用者在這段期間提出的要求和限制：
- 「我不想讓擬合函數去校準測量值，而是測量值能直接正比訊號」
- 「我可以讓我的指標承認誤差大，但不能估計錯誤的數據」
- 「我希望達到理論上的最佳數據處理，同時只做基本的假設」
- 「我想先討論真正的理論上限，也就是第一性原理決定的上限，假設紀錄沒有容量限制，每次讀出都取得一個iq點，其能給出的誤差極限會是多少，再來討論目前算法的資訊丟失是否發生在記錄層，還是分析層」

## 考慮過的選項與比較

### 模擬設定

以下各節的模擬共用這組設定：
- **讀出鏈每節：** 讀出 2 µs → 光子間隔 0.5 µs → A(x)，不設 relax。
- **qubit：** T1 = 20 µs，T2 = 15 µs。
- **掃描：** 每點 3×10⁶ 次讀出，61 點。
- **讀出：** g = 0，e = e^(0.7i)，每軸 σ = 1/SNR。讀出中 e→g 衰減機率為 d；衰減後的讀出值落在 g、e 之間，位置為 u，u ~ U(0, 1)。
- **兩種主要情境：**
  - 讀出衰減：p_th 0.3，d 20%
  - 熱：p_th 0.49，d 0
- **一般實驗：** relax 100 µs（5·T1）→ A → 讀出。兩種實驗每點的總時間相同。

### 讀出鏈中平均值和 r₁ 的形變

**曲線形狀：**
- amp Rabi 的平均值在 0.4–0.8 之間是平的，讀不出 π 振幅。
- len Rabi 的平均值在 2π 處才往下掉。
- Ramsey 的平均值有尖銳的凹陷。

**T1 擬合偏差。** 對無雜訊的平均值擬合指數，T1 得到 31.4 µs（讀出衰減）和 34.7 µs（熱），真值是 20 µs。

**r₁ 的布居偏差。** r₁ 的偏差來自 q(1−q) 隨 x 變化：
- amp Rabi 和 twotone 在讀出衰減時，q(1−q) 的最大值和最小值相差 2 倍。
- T1 相差 1.15 倍。
- 熱時固定在 0.25，所以 r₁ ∝ λ。

**修正平均值的方式。** 兩態穩態布居 q = P_ge/(P_ge + P_eg)。如果 A 只透過一個教科書函數 p 改變轉移，平均值嚴格等於 (c₀ + c₁p)/(1 + c₂p)：
- 無雜訊時，用這個有理式擬合，T1 得到 20.0000 µs。
- amp Rabi 得到 0.608 和 0.628（真值 0.6）。殘差來自脈衝期間的 T1、T2。
- 參數擬合中（模擬中 SNR 0.1、讀出衰減）：T1 偏差 −0.7%、sd 12%，教科書模型則偏差 +58%。

使用者沒有採用：「沒有relax_delay的平均通常沒什麼用，擬合出來的數值也難以相信，除非是twotone/freq這種本來就可以開很小relax_delay的實驗」。

### 合併平均值和 r₁

**做法。** 在參數層，把「平均值配有理式」和「r₁ 配教科書模型」兩個估計，依各自誤差的倒數平方加權平均。

**結果。** 合併會自動選到較好的一方，但也繼承了兩邊的偏差。例如 T1 在 SNR 0.3、讀出衰減時，合併後偏 −2.3%，單獨用有理式只偏 +0.2%。SNR 0.1 時，每次擬合自己報出的誤差也很吵，合併結果更偏：T1 讀出衰減時 −5.6%，熱時 −13%。

### λ 的估計：trace、joint v1／v2／v3

**trace 版本。** 用 r_ℓ = tr(C₀⁻¹C_ℓ) 做單一等比數列擬合，配 Fieller 型區間：
- 區間定義為 RSS(λ₀) ≤ χ²_{L−1}。
- 在 24 組 shot-level 模擬中，平均涵蓋率 0.67（名目 0.68）。
- Fisher ±1σ 只涵蓋 0.62，SNR 0.1 時只有 0.58。

**joint 版本。** 借用平均值估每點的振幅 B(x)：
- **v1：** B(x) 是平均值投影 m̃ 的自由二次式。
- **v2：** 限制 B 在資料範圍內為正，整體比例先做網格搜尋，區間計入 B 的不確定度。
- **v3：** 用 profile likelihood 估整體比例的不確定度。

v2 在 SNR 0.3 時的表現：
- 6 個實驗的涵蓋率是 0.69–0.87，λ 和真值的相關係數 0.99–1.00。
- Rabi 的 x_π sd 是 0.2%，trace 是 0.8%。

但 SNR 0.1 時，Echo（讀出衰減）的 λ 整段貼在 0 附近，涵蓋率只有 0.15。這不是比例的問題，而是 B 的形狀估錯了，v3 也救不回來。

### 前提的檢查

| 前提 | 使用者的判斷 |
|---|---|
| ① 相鄰讀出的雜訊互不相關 | 保證成立 |
| ② 鏈在穩態，讀出與 A 每節相同 | 保證成立 |
| ③ 同一點的讀出時間上連續 | 保證成立 |
| ④ 只有 g、e | 不一定是 g–e，但每點只有兩個態，某些點是 g–e，某些是 e–f |
| ⑤ 整段掃描讀出不變 | 保證成立 |
| ⑥ B(x) 能從資料估準 | 不成立 |
| ⑦ 雜訊公式只取低 SNR 主項 | 不成立，「snr可能高可能低，取決與測量點的dispersive shift與readout參數」 |

這張表讓 joint 版本出局：⑥ 不成立，而且 ④ 中不同點可能是不同的兩態。逐點 trace 或矩陣 λ 只需要 ①②③ 和「每點兩態」。

### 逐點的完整矩陣 λ

**模型。** 兩態時，白化後的 lag 矩陣嚴格等於 C̃_ℓ = λ^(ℓ−1)·W，W 是每點各自的秩 1 矩陣。λ 取 |Σ n_ℓ λ^(ℓ−1) vec C̃_ℓ|² / Σ n_ℓ λ^(2(ℓ−1)) 在 [−1, 1] 上的最大值，不需要迭代。

**模擬結果。**
- **顯示：** SNR 0.1 時，每點的 λ̂ 有很多點卡在 ±1，看不出趨勢。SNR 1 時清楚，只有 λ 過零的點會跳。SNR 3 時貼著真值。
- **參數擬合（直接擬合 lag 統計量）：**

  | 情況 | 偏差 / sd（trace → 完整矩陣） |
  |---|---|
  | x_π，SNR 0.1 | ±1% / 5–10%（兩者相當） |
  | x_π，SNR 1、3 | 約 0.1%，sd ≤ 0.2% |
  | T1，SNR 1 | sd 14% → 8.1%（讀出衰減）；8.5% → 6.8%（熱） |
  | T1，SNR 3 | sd 2.8% → 2.0%；1.4% → 1.4% |
  | T1，SNR 0.1 | sd 74–117%，不能用 |

- **用殘差校準的參數誤差不可靠。** 回報的誤差除以實際散布，trace 是 0.46–1.74，完整矩陣是 0.24–1.13。原因是單一全域倍數無法反映各點不同的雜訊，也無法反映同一點不同 lag 之間的相關。

### 等時間比較

這裡用 λ 的可見度（真值峰谷差 ÷ 每點誤差）和一般實驗平均值的可見度相比。

**逐點、基本假設。** 振幅每點自由時，λ 勝過一般平均的條件：

| 實驗 | SNR 0.1 | SNR 0.3 | SNR 1 |
|---|---|---|---|
| twotone、amp Rabi、len Rabi | p_th ≥ 0.33–0.44 | p_th ≥ 0.13–0.32 | 幾乎一律 |
| Ramsey、Echo、T1 | 幾乎只在 p_th ≈ 0.45–0.49 | 同左 | 同左 |

**全域兩態模型。** 每點 λ 的 sd 比逐點估計小：
- A 短的實驗：1.7–2.9 倍
- T1、Ramsey、Echo：3.9–5.9 倍

### 第一性原理上限（oracle）

**計算方式。**
- **完整 IQ：** 用前向演算法算隱馬可夫概似，以每條鏈 score 的共變異估 Fisher 資訊（2000 條鏈 × 400 次讀出）。
- **存下的統計量：** 統計量的真實共變異用 400 塊獨立的 shot-level 模擬量出，所以任何 SNR 都有效；Jacobian 用精確公式計算。
- **一般實驗：** 每發 shot 的混合密度做數值積分。

| T1，p_th 0.3，d 20% | 1 | 0.170% | 0.173% | 0.081% | 0.082% |

## 被否決的選項與理由

- **顯示多條曲線（平均、r₁、λ）。** 使用者：「太多曲線了，根本不知道要看哪個，就lambda就好」。
- **在讀出鏈中用平均值配有理式修正。** 這等於用擬合函數去校正量測值，而且讀出鏈的平均值難以信任。
- **把 r₁ 當指標。** 布居變化會造成幾 % 的偏差，例如 T1 在讀出衰減時偏 −3.5%。
- **用誤差加權合併平均值和 r₁。** 合併會繼承兩邊的偏差；SNR 0.1 時誤差本身也不可靠。
- **joint v1／v2／v3。** 依賴 ⑥，而且假設各點是同一組兩態；SNR 0.1 時會給出錯誤的數值，區間還偏窄。
- **在顯示中畫區間。** 使用者：「其實區間沒什麼用吧？至少在顯示上我不需要看，分析可能有用而已」。
- **用殘差校準參數誤差。** 回報的誤差和實際散布差 0.24–1.74 倍。
- **另做讀出校準實驗。** 使用者目前不考慮，傾向自校準。
- **分析只用 λ。** 第一性原理分析顯示，這樣會丟掉平均值通道：T1 在 SNR 0.3 時 sd 從 1.5% 變成 7.8%。顯示仍然只畫 λ，但分析應該兩個通道都用。

## 留下的問題

- **自校準估計器還沒做。** 做法是：全域兩態模型，每點由 (q, λ) 算出鏈轉移 P_x 的兩個元素，P_x 對教科書函數 p 是線性的，直接擬合；誤差用以點為單位的 sandwich 估計。偏差、誤差準確度、離上限多遠，都要在 SNR 0.1、1、3 下驗證。
- **「完整 IQ、讀出未知」的上限還沒算。** 這可以回答：在自校準前提下，多記錄直方圖或高階矩能不能縮小相對 oracle 約 5 倍的差距。推測低 SNR 時不能，因為分辨讀出中衰減需要三階以上的矩，資訊量正比於 SNR⁶。
- **sandwich 誤差還沒驗證。**
- **oracle 假設拖尾形狀已知**，模型也沒有「讀出把 g 激發到 e」這個機制。
- **全域模型和逐點基本假設的上限用的是低 SNR 雜訊主項**，SNR 1 時只是近似。
- **amp Rabi 的兩通道上限數值上沒解出來。**
- **SNR 0.1 時，每點 λ̂ 的顯示會有很多點卡在 ±1。** 要不要疊上擬合曲線，還沒決定。
- **哪些實驗改用讀出鏈還沒決定。** 選項有：只改 A 短的實驗、全部改、或兩種模式都提供。分階段做和實作計畫也還沒定。
- **一個踩過的數值陷阱。** 對尺度差很多的 Fisher 矩陣用 pinv 截斷，會把弱但真實的方向丟掉；有限差分 Jacobian 的相對誤差約 10⁻⁶，低於這個量級的特徵值只是數值雜訊。所以要先縮放、找出零空間、檢查可估性，再求逆。

## 依據
