# 一維反演量的誤差棒與圖上事實

## 結論

2026-11-23，使用者接受能從 shot 共變異推得的一維反演量誤差棒，並選擇讓一維讀出校正的圖與擬合都保留不截斷的估計。棒只算本次取數的抽樣誤差，不估計校正矩陣的不確定度。同日，使用者撤回把既有門檻判定放上圖的要求。圖可以報品質值或估計失敗；是否建議寫回、為何預選或不預選，留在 Writeback。現行規則見 [ADR-0069〈呈現規範〉](../adr/0069-experiment-core-and-frontends.md#呈現規範)與[實驗呈現指南](../../zcu_lab/v2/figure-style.md)。

## 問題

一維 circle 讀出校正原本把布居截在 0 和 1，誤差棒卻從截斷前的線性反演求得。若原始估計是 `−0.004 ± 0.006`，把點移到 0 而不改棒，就畫成了另一個估計量。另一方面，conditional phase 的普通與 heralded 分支，以及 local Z，都已有可傳到相位的 X/Y 計數變異，卻沒畫棒。

圖的舊規範也要求搬用既有選取判定。T2 Echo 的文件示例甚至把 R²、殘差與參數相對誤差同各自的門檻一起列在圖上，但當時沒有這樣的圖。若實作該示例，繪圖端還得從知道寫回門檻的地方取得判定。Mux Ramsey 的驗收也曾因圖沒說明某一 tone 為何未預選而退回。

## 選項與取捨

### 一維反演量的誤差棒

- 保留截斷值，再略過碰到 0 或 1 的棒，能維持原圖與擬合的值域。但靠近端點正是讀者需要知道抽樣誤差的地方，截斷也會抹掉估計跨過邊界的幅度。使用者選擇保留線性估計，例如讓 `−0.004 ± 0.006` 在圖上跨過 0，也讓擬合使用 `−0.004`。靠近邊界的點會因此改變 T1 等擬合結果。
- 既有資料足以傳遞一維讀出校正布居和計數相位的誤差。Raman 的兩個一維掃描與 STIRAP delay 本來就使用不截斷的估計；這次核對它們的棒。讀出校正只保存矩陣，不保存估計該矩陣的校正 counts。把矩陣視為已知，能用本次的 counts 計算誤差棒，不須改保存格式。
- Designer 沒有借用寫回的矩陣條件數門檻。條件數高不等於反演點或棒算不出來；不確定度增大時，較長的棒本身就是資訊。數值傳遞無法給出有限標準誤時才略過該棒並記 log。Wrapped phase 的棒在 ±180° 軸邊截斷，不繞到對側。六個 circle 入口連校正點也無法求得的情況，另見[一維讀出校正無解的討論](2026-11-23-singular-readout-analysis.md)。

### 圖上事實與寫回建議

保留原規則能讓讀者從圖直接看到操作介面為何沒有預選某個值，但把寫回判準帶進了客觀分析。使用者選擇讓讀者看事實再判斷：圖可以報擬合值、標準誤、R²、正規化殘差 RMS 和參數相對誤差。擬合失敗或標準誤算不出來也可以報，因為說的是有沒有得到數值。像 `not identifiable` 若指的是某個已算出的指標沒過門檻，就不能當作計算失敗寫在圖上。既有 Writeback review note 可以交代未預選的理由，不必另加從寫回到繪圖的傳遞方式。

## 未採用

沒有只在恰好等於 0 或 1 的地方刪棒，也沒有為了傳遞校正矩陣的抽樣誤差而增加存檔欄位。二維 map 不變。Readout gain／QND 診斷只有同圖的部分估計量有足夠的抽樣共變異，沒有替那些點單獨加棒。也沒有把機器判定換成較委婉的圖上標籤。即使判定出自既有 owner，它仍是寫回建議，不是擬合品質值。

## 留下的問題

T1 cov 的成對讀出積、R–π 的跨 lag 乘積與 readout gain 診斷的部分二階矩，都沒有保存估計其抽樣共變異所需的統計量。Fast-flux 相位與由相位導出的 detuning 只保存各格的平均 IQ，沒有該格的 shot 共變異。先在各 guide 說明缺項；如日後要畫棒，再決定該估計量需要哪些取數資料。
