# Tab 生命週期

**讀者：** agent。選擇、重用、保存或清理 GUI tab，以及驗證沿用值時，依本頁核對操作條件。

## 新建或重用

同一 adapter 連續調參或重複量測時，明確傳 `reuse_tab_id`。需要並排比較、改用不同 adapter，或刻意保留獨立工作頁時才新建。Recipe 未收到 `reuse_tab_id` 時會新建 tab。

重用前讀 tab 現況，確認上一個操作已結束。核對上一個 Run 的 raw 與本次判斷需要的分析、圖片或 writeback 證據已保存，並記錄實際路徑。Recipe 會 reset；要維持的 cfg overrides 或分析選項須重新傳入。

同名 canonical 圖片可能被後一次分析覆寫。需要比較舊模型或舊結果時，先依保存契約保留可辨識的證據，再 reset。

完成條件：新建或重用的理由已確認；重用前操作已結束，所需證據已保存，要維持的設定已明確傳入。

## 保存不完整

Terminal execution 只代表流程結束。逐項核對保存回覆的 artifact、實際路徑、錯誤與未知狀態。

Raw 或必要分析證據尚未保存時，先補保存；無法完成時保留 tab，記錄缺口並求助。核對完成前維持 tab 現況；逾時依 [Run measure GUI 的異常處理](../SKILL.md#4-處理逾時斷線與-stale) 確認操作狀態。重新分析同一 Run 時，保留對照所需的舊圖與分析設定。

完成條件：必要證據與路徑已確認，或 tab 保留且保存缺口已記錄並求助。

## 使用者的 tab 與清理

使用者擁有的 tab 預設保留。需要操作它時先核對當次授權及現有內容。

清理只透過明確的 `tab_close`。關閉前確認 target、操作是否仍在執行、保存是否完整，以及授權是否涵蓋關閉；未保存內容的 discard 需要明確授權。缺少條件時保留 tab，說明下一步。

任務結束按比較用途與當次授權，逐一決定保留或關閉 agent 的 tab。

完成條件：每個待清理 tab 的處理都有保存與授權依據；條件不足的 tab 維持保留，使用者 tab 的變更均有當次授權。

## 沿用值驗證

`cloned_from` 表示從其他工作點或條目複製。用於本工作點前至少快速驗證一次，並記錄來源、驗證條件與結果。

驗證要回答該值是否仍適用。按值的用途選擇驗證：頻率可先做授權內的短掃描；pulse 候選可用 Rabi 的週期與第一個峰核對；讀出參數要核對當前資料與讀出條件。

證據不足時保留「沿用、尚未驗證」，暫停依賴它的操作或求助。採用既有 offline 證據時，須確認它足以回答當前適用性。需要新的硬體或資料操作時先取得授權，驗證範圍以當次 policy 為限。

驗證通過後才據證據選擇使用或寫回。呼叫 `apply_writeback` 前核對所選候選及目的地。只批准部分時明確傳入 items，逐項核對授權。

完成條件：每個要使用或寫回的沿用值都有當前適用性的證據；尚未驗證的值已標記，依賴它的操作維持暫停。
